One sentence about a small moment of wonder in everyday life: raindrops racing down a bus window in little rivers — and the quiet surprise that the one I'm rooting for is the slowest of them all.

## Run it

```sh
python3 main.py
```

Writes the sentence (105 characters, one line) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Pure Python standard library, no dependencies. The program enforces the competition gate itself — 1–200 characters, single line, valid UTF-8, not blank, no doubled spaces — and verifies by reading the file back before exiting.
